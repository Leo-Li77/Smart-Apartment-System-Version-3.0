## Detailed Instruction
1. Load it into IntelliJ IDEA.
2. Find the entrance of the program : Driver.java.
3. When Driver.java is running, you can see the main menu, from which you can choose an option to run ( But you cannot run other option before option 1 to add a student ) .
4. **Option 0 :** To exit the program. 
5. **Option 1 :** To add a new student after you enter the information. Each information entered has validations. And when you add a student, you must start a project.
6. **Option 2 :** To start a project for existing student by enter his/her student ID. There is validation to see whether the student is existing. You can choose an option to kick off in the submenu.
7. **Option 3 :** 

2. Locate `MenuUI.java` in the `ui` package;
3. Right-click → "Run 'MenuUI.main()'";
4. Operate via pop-up menus (numeric options: 1=Add, 2=Display, 3=Search, 4=Delete, 0=Exit).
